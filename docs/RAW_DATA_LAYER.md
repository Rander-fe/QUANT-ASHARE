# 第0层：原始数据目录

第0层只登记可以作为研究输入的事实数据，不包含因子、标签、模型特征或回测结果。

## 文件

- `config/raw_data_catalog.json`：人工维护的数据契约，记录来源、粒度、必需字段、单位和时间可用性。
- `data/catalog/raw_data_inventory.json`：审计程序生成的本机库存，记录实际文件、行数、物理字段和契约错误。
- `data_catalog/audit.py`：只读审计程序。

## 使用

```powershell
python -m data_catalog.audit
# 或通过项目统一入口
python main.py audit_raw_data
```

审计只读取 Parquet 元数据、SQLite 表结构和一个JSON样例，不加载大型数据表。返回码为0表示所有必需文件和字段存在；返回码为1表示契约错误。

## 时间可用性铁律

1. 日行情在收盘后才完整可用，使用当天收盘数据生成的信号最早在下一交易日执行。
2. 财务数据必须按实际公告日做PIT关联，不能按报告期末 `end_date` 回填。
3. 当前证券名称和ST状态是快照，不得回填到全部历史日期；历史名称使用 `namechange.parquet`。
4. 文本历史文章在完成可获得性审计前，以 `first_seen_at` 作为保守可用时间，不能只按文章标注的 `published_at` 回测。
5. `factor` 是行情复权因子，属于原始数据输入；`factors.parquet` 是选股因子产物，属于第2层及以后，两者不能混淆。

## 已知缺口

- `cashflow.parquet` 当前只有标识字段，没有现金流数值字段，需要后续重新抓取或从其他已有财务字段核对补齐。
- OHLCV的价格、成交量和成交额单位继承Qlib数据源口径，目录已标记为“使用前必须复核”，第1层算子建设前应做单位验证。
- `stock_basic.parquet` 中 `is_st_now` 是当前快照；历史ST状态仍需专门的PIT数据源。
- 行业字段已经确认来自当前 `stock_basic` 快照并回填全部历史日期，历史行业因子暂时禁用，直到接入带生效区间的行业成分。
- 每日扩展底表把估值缺失值填为0；目录通过 `missing_value_sentinels` 标记这些字段，进入算子前必须恢复为NaN。
- 政策文本已有采集时间，但1074条记录的正文全部为空，目前只能做标题级研究；真实首次公开可得时间也尚未独立审计。
- `fina_indicator` 有1条不可能时序记录：`603400.SH / 20260630 / ann_date=20260422`，使用前必须排除或核验。
